# Kaggle Walmart Sales Forecasting Competition

Kaggle Competition: [Walmart Sales Forecasting](https://www.kaggle.com/competitions/walmart-recruiting-store-sales-forecasting)

This project is using machine learning methods to try and predict the amount of sales that Walmart will have depending on the time of year. 

## Usage
1. Download test and training datasets
2. Download R file
3. Run the code
